Hazbin Hotel & Helluva Boss API

Official fan-made API documentation providing structured access to characters, species, universes, and weapons from the Hazbin Hotel and Helluva Boss universes.

/species/demon

Weapons Endpoints

GET /weapons

/weapons

Returns all registered weapons.

GET /weapons/{weapon_name}

/weapons/angelic_spear

Accepted values for weapon_name:

Technologies & Frameworks

This API was built with a strong focus on performance, safety, and scalability. We're using the following technologies:

  • Rust – memory-safe, high-performance systems programming language
  • Axum – modern, ergonomic, and async-first web framework
  • SQLx – asynchronous, compile-time checked SQL toolkit
